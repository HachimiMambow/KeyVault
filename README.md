# KEYVAULT

Trabalho acadêmico desenvolvido para a disciplina de **Interface Homem-Máquina** do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas (Turma 2ADS).

## Sobre o Projeto
O projeto consiste no desenvolvimento de um website funcional baseado no protótipo e documento de requisitos elaborados pela equipe. O sistema foi construído utilizando apenas tecnologias nativas da web, sem o uso de frameworks ou templates externos.

## Tecnologias Utilizadas: 
  - **HTML5** — Estruturação semântica das páginas
  - **CSS3** — Estilização, layout e responsividade
  - **JavaScript** — Validações de formulários e interações dinâmicas
